# טעמים מהבית — ספר המתכונים שלנו

**Collaborative desktop recipe book** built with **WPF** + **WCF** + **SQL Server**.

פרויקט בגרות במגמת מדעי המחשב (כיתה י״ב) — פיתוח אפליקציות אסינכרוניות.  
נכתב באופן עצמאי במסגרת הלימודים בסמינר פניני חן (2023).

---

## הרעיון

מתכונים הולכים לאיבוד בגלריית התמונות, באפליקציות שונות או בדפים ממגזינים.  
**טעמים מהבית** מרכזת את המתכונים מהבית במקום אחד, דיגיטלי ומשותף — עם חיפוש, סינון לפי אלרגנים, דירוגים וצ׳אט סביב כל מתכון.

קהל היעד: כל מי שאוהב לבשל, לאפות ולשתף מתכונים מהמטבח של הבית.

---

## יכולות עיקריות

### משתמש
- הרשמה והתחברות
- העלאת מתכונים מהבית (שם, תיאור, מרכיבים, אופן הכנה, הערות, תמונה, זמן, רמת קושי, כמות מנות)
- עריכת המתכונים שלי
- חיפוש וסינון לפי שם ואלרגנים (גלוטן, שומשום, חלב, אגוזים, סוכר, סויה, ביצים)
- תיקיות מותאמות אישית (למשל «מרקים»)
- מועדפים ודירוג עד 5 כוכבים
- צ׳אט קטן לכל מתכון — שאלות, טיפים והחלפת רעיונות

### מנהל
- ניהול הודעות (הסרת תוכן לא הולם)
- אימות מרכיבים וסימון אלרגנים
- תקינות יחידות מידה (כוס, כפית וכו׳)

## ארכיטקטורה

המערכת בנויה בארכיטקטורת **לקוח–שרת**:

| שכבה | תפקיד |
|------|--------|
| **Model** | מחלקות מראה לטבלאות במסד הנתונים |
| **ViewModel / DAL** | גישה ל־SQL Server, CRUD וסינונים |
| **WCF Service** | שירות רשת מרכזי (`IRecipeService`) + העברת תמונות |
| **WPF Clients** | ממשק משתמש וממשק מנהל (XAML + C#) |

```
├── ClientRecipeEstiGenauer/
│   ├── UserClientRecipeEstiGenauer/   # אפליקציית משתמש (WPF)
│   └── ManagerRecipe/                 # אפליקציית מנהל (WPF)
├── ServerRecipeEstiGenauere/
│   └── ServerRecipeEstiGenauere/
│       ├── Host/                      # הרצת שירות ה־WCF
│       ├── WcfServiceLibrary2/        # חוזה השירות והמימוש
│       ├── Model/                     # ישויות
│       └── ViewModal/                 # שכבת מסד נתונים
└── RecipeBookPictuers/                # נכסים גרפיים לממשק
```

### טבלאות עיקריות במסד
`WebUser` · `Recipes` · `Folders` · `Ingredients` · `RecipeIngredient` · `Yechidot` · `FavoriteRecipes` · `Rating` · `RecipeMessages`

## טכנולוגיות

- **Visual Studio 2019**
- **C# / .NET Framework**
- **WPF** (XAML + C#) — צד לקוח
- **WCF** (`basicHttpBinding`) — צד שרת / תקשורת
- **Microsoft SQL Server LocalDB** — מסד נתונים

---

## איך מריצים מקומית

1. ודאי שמותקנים Visual Studio ו־SQL Server LocalDB.
2. פתחי את ה־solution של השרת והריצי את פרויקט **Host**  
   (השירות רץ על `http://localhost:8733/.../RecipeService/`).
3. השאירי את חלון השרת פתוח.
4. הריצי את **UserClientRecipeEstiGenauer** (משתמש) או **RecipesmanagerEsti** (מנהל).
